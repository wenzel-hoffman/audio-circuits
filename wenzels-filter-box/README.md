# Wenzel’s Filter Box

A simple guitar pedal with a pair of filters (hi-pass and low-pass).

## Features

- Runs from 18V to 36V (plenty of headroom)
- Aggressive RC supply filtering stages
- RF filtering
- TAME knob for a low-pass filter (LP ≈20–21kHz → ≈486Hz)
- TIGHT knob for a hi-pass filter (HP ≈30Hz → ≈720Hz)
- Buffered output
