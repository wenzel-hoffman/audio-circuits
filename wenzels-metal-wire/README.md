# Wenzel’s Metal Wire (overdrive/preamp/amp-in-a-box)

This is my take on the “Steel String” pedal.

The differences compared to the original are:

1. It runs from 18V to 36V
2. Has aggressive RC supply filtering stages
3. Has extra RF filtering
4. Uses shared filtered Vbias for Q2 and Q4
5. Replaces B100k linear volume pot with A100k logarithmic
6. Features extra TAME knob for a low-pass filter (LP ≈20–21kHz → ≈486Hz)
7. Features extra TIGHT knob for a hi-pass filter (HP ≈30Hz → ≈720Hz)
8. Features a buffered output
