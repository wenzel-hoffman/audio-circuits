# Wenzel’s Transformer Isolation Box

Passive TY-250P isolation box for 2 inputs and 2 outputs. Featuring A25k volume
potentiometers, phase polarity and ground lift switches.

I desgined it for my pedalboard needs. In particular for WET-only chain
commutation.
